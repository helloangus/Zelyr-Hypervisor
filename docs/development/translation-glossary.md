# Documentation translation glossary

Chinese readers can use the [Chinese edition](translation-glossary.zh-CN.md).

**Status:** Informative translation aid.
**Scope:** Preferred Chinese renderings of common repository document terms; identifiers and contracts remain in their source documents.
**Version:** v0.1
**Owner/change context:** Bilingual documentation rollout.
**Supersedes:** None.

This glossary improves consistency across translations. It has no independent
normative force; [documentation governance](documentation-baseline.md) owns
translation authority and synchronization.

| Source term | Chinese rendering | Handling |
|---|---|---|
| Stage Task Book | 阶段任务书 | Keep stage ID and version unchanged. |
| work package / work-package plan | 工作包／工作包计划 | Keep `P<stage>-Wxx` IDs unchanged. |
| detailed implementation design | 实施级详细设计 | Do not equate it with a task book or package plan. |
| implementation record | 实施记录 | Preserve factual status and dates. |
| verification evidence / report | 验证证据／验证报告 | Never strengthen a claim during translation. |
| completion report | 完成报告 | Preserve scope and exclusions. |
| normative / informative | 规范性／资料性 | A translation itself has no independent authority. |
| required / reserved / out of scope | 必需／预留／范围外 | Preserve each item's classification. |
| Host / Guest | Host／Guest | Keep architecture terms recognizable. |
| Stage-2, EL2, vCPU, GIC, ABI, QEMU | 原样保留 | Technical identifiers remain unchanged. |
| `unsafe`, `no_std`, Cargo, Rust | 原样保留 | Do not translate code tokens. |

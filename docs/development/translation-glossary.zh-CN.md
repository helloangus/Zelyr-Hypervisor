| 英文原词 | 中文译法 | 处理方式 |
|---|---|---|
| Stage Task Book | 阶段任务书 | 阶段 ID 与版本保持原样。 |
| work package / work-package plan | 工作包／工作包计划 | `P<stage>-Wxx` ID 保持原样。 |
| detailed implementation design | 实施级详细设计 | 不将其等同于任务书或工作包计划。 |
| implementation record | 实施记录 | 保留事实状态和日期。 |
| verification evidence / report | 验证证据／验证报告 | 翻译不得强化声明。 |
| completion report | 完成报告 | 保留范围和排除项。 |
| normative / informative | 规范性／资料性 | 译文自身不具独立权威。 |
| required / reserved / out of scope | 必需／预留／范围外 | 保留每项分类。 |
| Host / Guest | Host／Guest | 保持架构术语易于识别。 |
| Stage-2、EL2、vCPU、GIC、ABI、QEMU | 原样保留 | 技术标识符不翻译。 |
| `unsafe`、`no_std`、Cargo、Rust | 原样保留 | 代码 token 不翻译。 |

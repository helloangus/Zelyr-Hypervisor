**Scope:** P2-ACR-01；最小架构无关内存所有权与映射视图基础，以及 P2／P4 生产者边界；不涉及新公共 ABI、共享／捐赠策略、DMA、Guest 生命周期或调度策略。
**Context:** 已接受的[中文 ADR-000](adr-000-architecture-baseline-v0.1.md)第 15 节 P2 要求“定义 MemoryObject/MemoryRegion 的最小数据结构”，第 4／6 节区分后备所有权与地址空间视图。[P2 任务书第 3 节](../stages/p2/task-book-v0.1.md#3-architecture-change-record)记录它与 P2 不设计 P4 对象系统的边界冲突。W11 和 P4 早先拟议的阶段局部句柄不能默默替代架构所有权模型；P4-W10 范围授权没有解决此冲突。
**Decision:** 责任方已选择方案 A：P2 拥有最小通用 MemoryObject／MemoryRegion 基础，P4 拥有 Guest 专属集成。保留既定阶段归属，通过下述有界后续工作澄清任务书边界。接受前不具有规范效力。
**Consequences:** 责任方已授权有界 [P2-W12 计划](../stages/p2/plans/p2-w12-minimal-memory-objects.zh-CN.md)，W11／P4 运行准入前协调消费者。W04 按责任方要求视为未实现且排除本次提交，不证明物理分配或对象模型交付，不扩大任何完成声明。
**Alternatives considered:** B：将通用基础移到 P4，显式修改 ADR 的 P2 时序，并允许有界临时 Host 映射例外；会推迟通用所有权协调，还需明确例外终止／升级规则。C：只添加空结构或无限期使用裸帧／视图元组；提案不推荐，因为表示形式不等于所有权或映射生命周期保证。

## 1. 责任方已选择的有界决定（方案 A）

责任方已授权单独规划的 P2 工作包 **P2-W12**，提供架构无关的后备所有权及地址空间视图生命周期。
它须交付最小语义，而非仅增加类型名称：

- MemoryObject 独占分配器产生的一份后备分配（或有界集合），具有明确身份和生命周期。
  首版只覆盖普通自有 RAM；外部后备、转移／共享保留。裸物理地址不是所有权证据。
- MemoryRegion 表示某地址空间内对对象范围的有界视图，记录范围、权限／内存类型意图和映射生命周期，
  不包含 Host／Guest 描述符或寄存器编码。
- 存活或进行中的映射保留后备；撤销映射后，所属后端完成失效／静止，才能释放。
  清理失败或结果不确定时保留所有权；超时不是释放凭证。对象／视图身份不得复用后静默混淆。
- Host Stage-1 和 Guest Stage-2 后端拥有实际映射权、表、排序及执行约束；
  通用对象不能用普通布尔值声称硬件完成，也不能伪造后端释放权威。
- W04 仍拥有物理分配／释放；W12 基于其所有权句柄。
  W11 通过架构适配器映射 Host 视图；P4-W03 拥有 Guest RAM 内容／加载，P4-W02／W10 拥有 Guest 映射／上下文／退役。

具体 Rust 表示、API、借用／token 方案、有界存储及计数留给后续详细设计，本 ADR 不替它们作决定。
共享、捐赠、DMA／IOMMU、COW、热插拔、VM 创建、公共能力 ABI、Guest 策略及 Stage-2 机制不进入 P2。

## 2. 若获接受，后续工作与依赖约束

1. 协调 P2 任务书第 3 节，增加有验证追踪的 W12 计划；不修改已接受基线来抹去历史冲突。
2. W12 依赖 W04 所有权与地址类型，不依赖 W11 硬件映射。通过注入后端的 Host 测试验证对象／视图生命周期，
   不把它当作转换后访问证据。
3. W11 对应的生命周期集成依赖 W12；窗口／架构／回滚审阅保持独立。
   W04 元数据映射是镜像／启动生命周期基础，不要求先通过新分配器对象 API 引导自身。
4. P4-W02／W03 单 Guest 及 W10 多 VM 扩展在运行准入前协调通用后备／视图权威。
   通过获审阅设计移除或显式适配阶段局部替代物；只改名或复制所有权台账不算集成。
5. 保留 P3 SMP 准入边界；P2 启动 CPU 对象证据不证明并发对象使用或跨 CPU 失效安全。
6. 分开记录决定和交付：接受解决 P2-ACR-01 归属／范围冲突；实现与验证关闭基础交付。

## 3. 后续工作包所需验收证据

测试／审阅对象所有权、有界范围和权限校验、旧身份拒绝、映射保留、创建／映射失败回滚、
失效失败保留、无映射时释放、重复复用及精确分配计数。
Host／Guest 适配器在各自阶段独立验收；Host 夹具不声称实际 Stage-1／Stage-2 或 SMP 行为。
P2-W10 及 P4／P7 输入审阅按条件消费链接证据。

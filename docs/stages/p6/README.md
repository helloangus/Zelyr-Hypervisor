# P6 — Timer, GICv3, and Virtual Interrupt v0

The normative P6 scope is [task-book-v0.1.md](task-book-v0.1.md). Start a
specific package from the [work-package plan index](plans/README.md), which
maps P6-W01 through P6-W13 to prerequisites and downstream consumers.

This directory separates stage planning, approved detailed design and
implementation traceability, and verification evidence. A P6 work-package plan
does not authorize code changes or replace an approved detailed design. P6 does
not claim to implement a scheduler, Linux-visible vGIC machine model, Guest
SMP, or a frozen machine ABI.

# Stage documents

**Status class:** normative (per the
[documentation baseline](../development/documentation-baseline.md)).

Each `p<stage>/` directory holds that stage's task book, work-package plans,
implementation designs and records, and verification evidence in their
separated sublocations. The [P0 stage](p0/README.md) is the engineering
baseline; later stages follow the same layout. Start from the
[documentation index](../README.md) routing table.

# P8 — Virtual ARM Platform and Minimal Linux Boot

The normative P8 scope is [task-book-v0.1.md](task-book-v0.1.md). Start with
the [work-package plan index](plans/README.md), then obtain an approved detailed
design before any code change.

This folder separates planning, later implementation traceability, and
verification evidence. The plans describe bounded outcomes and do not freeze a
machine ABI, select a machine layout, define an API, or claim implementation.

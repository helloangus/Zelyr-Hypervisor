# P3 — Host SMP and per-CPU foundation

The normative P3 scope is [task-book-v0.1.md](task-book-v0.1.md). P3 plans
may begin only after the P0, P1, and P2 prerequisites named there are
demonstrably available. This stage establishes host physical-CPU foundations;
it does not create a VM, Stage-2 translation, a vCPU scheduler, a virtual GIC,
or guest SMP.

Read a specific package from the [work-package plan index](plans/README.md).
Plans establish bounded outcomes, acceptance evidence, and handoff. They are
not detailed designs, implementation records, verification evidence, or a
claim that P3 has been completed.

# P5 — Hypercall, object handles, and Capability v0

The normative P5 scope is [task-book-v0.1.md](task-book-v0.1.md). Start a
specific package from the [work-package plan index](plans/README.md), which
maps P5-W01 through P5-W10 to prerequisites and downstream consumers.

This directory separates stage planning, later approved detailed-design and
implementation traceability, and verification evidence. P5 plans establish
bounded outcomes, acceptance, and handoff; they do not freeze or design the
Hypercall ABI, module/API structure, register convention, handle encoding,
rights encoding, or concurrent implementation. The ABI and security documents
required by P5 are factual implementation-stage deliverables, not claims made
by this planning set.

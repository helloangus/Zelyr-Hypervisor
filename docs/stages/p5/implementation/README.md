# P5 implementation and detailed-design records

Store approved P5 detailed designs, implementation traceability, ABI/security
artifacts, decisions, and limitations here after the applicable work package
has reached that point. Do not treat a plan as an approved detailed design or
as proof that code, an ABI, or a security control exists.

Actual test commands, environments, logs, and results belong in
[`../verification/`](../verification/). Versioned ABI contracts that become
applicable to consumers belong under [`../../../abi/`](../../../abi/), with a
link from the relevant record here.

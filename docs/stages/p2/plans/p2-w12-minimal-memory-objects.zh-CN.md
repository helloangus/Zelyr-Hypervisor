## 目标

交付最小架构无关 MemoryObject 后备所有权及 MemoryRegion 映射视图生命周期基础，
供 Host／Guest 映射消费者使用，保持 ADR 的后备所有权与地址空间视图区分。

## 范围

必需 P2-N01–N06／P2-V15：分配器产生的普通 RAM 所有权；稳定且受检查的身份与有界容量；
对象范围／权限／内存类型视图校验；预留、发布、存活映射及撤销期间保留所有权；
后端完成清理后才能释放；失败保留与精确分配计数；独立 Host／P4 适配器交接。

W04 是唯一物理分配／释放权威。W12 保留其实际所有权句柄，不另建帧所有权台账。
Region 是视图，不能成为第二后备所有者。裸 HPA 或普通布尔值不能证明所有权或失效完成。
首版限启动 CPU，明确独占执行和生命周期约束。

W12 依赖 W04 所有权与地址类型，不依赖真实 W11 映射。注入后端允许先做 Host 生命周期测试。
W11 仍拥有 Host 转换；P4-W02／W10 拥有 Guest 转换；P4-W03 拥有 Guest 内容／加载。
最终适配器须消费同一对象／视图权威，不复制所有权。

保留：外部后备、共享／捐赠、DMA／IOMMU、COW、热插拔及后续经 P3 审阅的并发使用。
必须兼容这些扩展，但本包不实现其策略或机制。

## 范围外

Host／Guest 描述符编码或寄存器操作、W04 元数据引导、VM／vCPU／GuestAddressSpace／VMID、
公共管理／能力 ABI、调度策略、SMP 锁或跨 CPU shootdown、裸地址导入所有权，
以及在计划中冻结新模块、Rust 签名或存储算法。

## 工作顺序

1. 检查 W04 身份、移动／错误／释放语义、地址类型、W11 生命周期／回滚需求及 P4 交接，
   记录缺失输入和 ADR 决定／集成状态，不虚构获批 API。
2. 形成并审阅对象／视图状态、所有权权威、有界存储、身份耗尽、构建失败、保留／释放及
   后端完成权威的详细设计，并取得编码准入。
3. 使用注入存储／后端接口实现获批的纯所有权／视图基础，保持真实 W04 所有权和计数。
4. 验证正常／拒绝生命周期、无效／溢出范围、权限／类型不匹配、旧身份、容量耗尽、
   部分映射失败、清理失败、token 遗失及重复释放／复用。
5. 协调 W11 Host 适配器及 P4-W02／W03／W10 消费者设计，区分模拟完成与各后端架构／执行／静止证据，
   不以裸地址或重复台账绕过权威。
6. 向 W08／W09／W10、P3／P4 交接实际契约、证据、集成要求及限制。
   硬件／SMP／Guest 门禁等待所属阶段证据。

## 验收与闭环

P2-V15 要求：每份后备只有一个所有者；视图有界且不超出后备生命周期；存活／进行中／清理失败的视图保留后备；
只有经过审阅的后端完成权威允许撤销和释放；调用错误保持所有权；复用拒绝旧身份；耗尽及计数明确正确。
缺失或被遗忘的 token 必须保留资源，不能静默释放硬件仍可见的后备。

Host 模型只证明模型中的生命周期／所有权。W11 的 V14、W09 的 V11 独立证明真实 Host 映射访问；
P4 负责 Guest 转换／退役证据，P3 负责 SMP 扩展。V12／V13 移交评审必须区分这些边界。
计划、空类型或模拟回调成功不满足执行验收。

## 交接

W11 消费通用后备／视图生命周期权威，仍拥有 Host 映射／撤销。
P4-W03 集成 Guest 后备而不拥有转换；P4-W02／W10 消费有界视图，保留映射／上下文／退役权威。
W08 消费失败／生命周期场景；W09 测试集成 Host 使用；W10 发布按能力区分的证据。
W04-MAP 不进入该依赖链，避免引导循环；不默默增加 W05 堆集成。

## 目标

为 P2 的不可信输入、内存图、分配及确定性发现安全性质定义可复现的 Host 侧回归证据。

## 范围

P2-J01–J05：格式错误的 DTB、内存图冲突和范围溢出、
分配耗尽／复用／受保护页安全、分配压力，以及相同输入的确定性发现。

## 范围之外

QEMU 集成执行、模糊测试架构、性能基准、实施测试命令，
或在规划期间捏造验收证据。

## 工作顺序

1. 收集 W01–W05 的安全成果及 W07 的样本／就绪预期，作为待测断言。
2. 定义证明有界拒绝和诊断所需的错误 DTB 案例，覆盖结构、编码、截断和溢出输入。
3. 定义内存图冲突与分配器生命周期案例，包括禁止返回的全部受保护页及耗尽／释放后的复用。
4. 确立确定性重复输入及伪随机压力证据预期，附带核算／不变量检查。
5. 评审 Host 侧结果所证明的逻辑性质，明确其不能替代 QEMU 或真实硬件语义。
6. 向 W09 和 W10 移交可复现回归套件的要求。

## 验收与关闭

P2-V10 要求 P2-J 每组都有真实、可复现的证据：错误输入的有界处理、
冲突／溢出处理、耗尽／复用、受保护页安全、压力一致性及重复发现的确定性。
本计划不声称已有证据。

## 移交

W09 可将已建立的 Host 侧安全基线与参考平台集成结合。
W10 可记录证据位置和未测试的限制。

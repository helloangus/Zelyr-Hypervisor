## 目标

提供安全、可观测的 Host 物理页分配与释放能力，绝不返回 W03 保护的范围。

## 范围

P2-E01–E08：分配／释放、页对齐、多 RAM 区、明确的 OOM、受保护页安全、
调试错误检测，以及托管／空闲／已用／保留页核算。

## 范围之外

选择 buddy、bitmap 或其他分配器；大页策略；具体分配器 API；
Guest 内存所有权移交；或 SMP 并发设计。

## 工作顺序

1. 确认 W03 的规范化内存图标识唯一允许的分配范围以及所有永久排除的范围。
2. 定义分配、释放、对齐、耗尽、多区域处理和核算的工作包成果。
3. 确立无效释放、重复释放、非托管范围释放和核算不一致的验证／调试预期。
4. 评审安全边界，确保便捷路径不会重新引入固件、DTB、镜像、启动制品或元数据页。
5. 指定在碎片化内存配置下分配／释放／OOM 和受保护页的证据。
6. 向小对象分配、检查、P3、P4 和回归消费者移交分配契约。

## 验收与关闭

P2-V06 要求证据覆盖明确的分配／释放／对齐／多区域／OOM／调试／核算行为，
且受保护页返回次数为零。P2-V10 和 P2-V11 以压力测试和 QEMU 集成证据扩展验证。

## 移交

W05 可从此工作包取得支撑基础。P3／P4 可依赖已记录的能力和限制，
而非某个已选定的分配器实现。
